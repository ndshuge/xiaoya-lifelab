# 小芽 V4 · Apple 触控与文字精修（2026-11-03）

## 目的
让原独立仓库已上线的「今天｜事项｜发展」符合小芽品牌下的 Apple 风格，确保用户真正在 iPhone 上读得清、点得准、页面不跳动。

## 方案比较
A. 把每张内容卡改成“玻璃”并新增动效：视觉噪音/性能成本高，拒绝。
B. 保持目前三栏和真实功能，以排版、减法、触控命中、日程定位为主，保留唯一头像及浮动 Dock：**采用**。
C. 重新写 SwiftUI / React：会丢失既有浏览器存储与静态 Pages 能力，拒绝。

## 内容与交互
1. 保留「今天｜事项｜发展」、合成演示数据标注、实际 DDL 提醒、日记、导出、模型接入等真功能。
2. 移除 YOUR DAY / TO DO / DEADLINES / TIMELINE / JOURNAL / LOOK BACK / REFLECTION / GROWTH / ANYTIME / UPCOMING / TODAY 等纯装饰英文小标签；删除重复口号，不弱化真实隐私告知。
3. 主题行文保留中文、简洁、可理解。信息型小字提升至不少于 12px，功能按钮/列表操作具备 44×44 CSS px 可点区域，图标本身仍保持克制。
4. 进入日程时滚动内层时间轴到第一项真实课程/活动附近，不改数据模型、不“创建”课程；当日无课程维持真实空状态。
5. 弃用“隐藏小芽”开关：V4 无独立陪伴面板，小芽头像承担唯一对话入口。保留旧 localStorage 属性以保证 V3 兼容。
6. Dock 保持 L1 渐变模糊并覆盖 safe-area；不虚称 L2 真折射。面板开合保留可中断动画，尊重减少动效及减少透明度。
7. 不改正式入口、V3 原件或其他施工线；以本地干净 worktree 修改，核验后按非强制流程发布。

## 用户评价项
可读性、点击不抖动、无多余装饰文案、信息层级、交互可逆性、空态、真实日期、键盘操作，390/320/768/1440 与 WebKit 检查。真机 Safari 仍需人手验收。

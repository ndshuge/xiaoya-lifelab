## 核心设计哲学
1. **一页只解决一个问题**：「今天」看下一步与建议；「事项」安排/收集；「发展」记录状态或追踪目标。
2. **动作跟随内容**：删除顶部每页统一“+”；在对应内容分组用文字描述创建对象；隐藏无用冗余 CTA。保留唯一头像与设置入口。
3. **常用动作 2 个字段完成**：新建待办只出现标题及可选截止日期；类别、关联课程、预计分钟、网页提醒放进“更多选项”；编辑既有事项默认展开以确保字段可见。保留原校验与存储 schema。
4. **日期语义真实**：在日期栏创建截止提醒时预填所选日期 23:59，独立待办创建则不预填 DDL；任何 DDL 均不变成真实日程块。
5. **发展二级分组，非无底长页**：同一主页面内「记录｜目标」分段。记录显示心情/日记/历史/趋势，目标显示行动记录/目标/成长路线。不删除已有功能。分段切换尽可能不重建 DOM，防止正在输入的日记被擦掉。
6. **首屏更短**：首页已有“今天日程结束”卡片后不再默认展开所有已结束时间轴；允许主动查看，保留时间线访问入口。对有正在进行/待开始课程的时间线完整显示。
7. **不为了仿 Apple 加新控件**：使用原本的头像、字体层级和低噪声材质；不追求添加不必要玻璃、阴影、星形图案。
8. **安全与品质**：44px 控件、无抖动、Dock 不挡内容、键盘/减少动效、个人/演示档案隔离、日记不自动传给 AI，历史 V3 不动。

## 方案与取舍
- A：继续改字号、圆角与 blur。**否决**：没有改变长表单和多按钮根因。
- B：本轮采用：微调现有 V4 页面结构、事件处理和表单，保持成熟数据逻辑、只在代码局部重排。
- C：重写成 React / AppFlowy 风格。**否决**：损失历史功能、隐私隔离和比赛部署稳定性。

# 小芽生活小岛｜海洋生态增量设计

**基线**：ndshuge/xiaoya-lifelab main @ 5b12831（2026-11-06）。
**方向**：保持原纸艺陆地、场景 UI 与应用数据，给现有海水着色器增加水底层次、鱼群与夜间灯塔扫光。不要替换 Astro 或将它当成全新的海岛应用。

## 既有能力与约束
- Three.js r180、单面 Shader 海水、双船/兔子/海鸥、DDL 语义灯塔、日周长线、paper-kit 折叠、reduce-motion、Lite 档都保留。
- `index.html`、评委 `?judge=1`、Native V4、原业务库、localStorage 均不得修改。
- 无外部模型/贴图，水下效果通过 GLSL 在已有海面 pass 绘制；鱼群在低帧消耗与可读性之间取舍。
- 海面只有非交互空白区域能触发鱼群惊散；日程牌与灯塔的 Raycast 优先。
- 仅在有实际截止事项的周岛创建灯塔扫光，白天不渲染，夜间渐显。

## 方案评估
1. 迁移 Astro/完整重做：不选，破坏当前项目结构和版本连续性。
2. 透明水面 + 独立水下网格：暂不选，会增加移动端 alpha-overdraw。
3. **选用**既有水面单通道加沙纹、稀疏海草/礁石、移动焦散与程序化鱼影；鱼群位置用纯计算 uniforms 更新。

## 验收
纯函数测试覆盖鱼群分组、越岸、惊逃与恢复、Shader 功能/轻量档、纸灯塔折叠。自动化真实运行 Chrome/Edge 桌面/移动 + WebKit，检查点击、夜间、低动态和无控制台错误。真机 iPhone Safari 与最终艺术验收独立标记。

# 小芽小岛：海水生态增量升级（2026-11-08）

## 意图与约束
在现有 Opus Original / Three.js r180 小岛内增加更有层次的海水与可互动鱼群。陆地与纸艺视觉、灯塔的截止事项含义、小芽行走与日周长线、业务数据、已有历史版、评委固定链接均不可改变。原有的海水浪高与船只运动保留。保持离线/静态 GitHub Pages 可用，手机降低粒度，弱动画偏好受尊重。

## 方案权衡
- 重写 Astro/海岛：破坏当前架构与产品状态，排除。
- 全水下真实 3D + 折射后处理：质量上限较高，但移动成本与既有透明层耦合较高，暂不采用。
- **选择：在现有 ShaderMaterial 插入独立水底着色层 + 有界鱼群位置计算与交互涟漪**，不改变海面网格和业务模块。动态数据经 Three.js uniforms 写入，鱼群以低成本水面下剪影呈现。

## 可验收结果
1. 近岸细沙与沙纹、分布有节制的海草/暗色礁石、水底焦散；远海过渡到深蓝绿，昼夜照明联动。
2. 鱼群围绕岛屿自然游动；点击可见海面形成短暂涟漪、鱼群向外逃开并返回；拖动旋转、岛上选择与移动不得误触发。
3. 低动态模式停下海水和鱼群且不产生涟漪；手机简化 shader 和鱼群数量；原海浪/小船沿用同一 waveHeight 函数。
4. 有可复现的纯函数测试、浏览器 WebGL/交互检查；不修改私人数据、旧版或路由。

## 界面与质量
纸艺暖沙 + 克制的青绿色海水，保留小芽世界视觉识别。水下细节只出现海岸浅水区，不压过内容旗帜、日期与人物；音频采取后续可选用户手势激活，不自动播放。

## 发布边界
先在独立 feature 分支测试；如未被额外明确授权，不直接发布/修改 main。已存在的根入口、?judge=1 与数据键一字不动。

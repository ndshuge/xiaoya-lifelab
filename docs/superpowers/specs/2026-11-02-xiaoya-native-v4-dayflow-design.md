# 小芽 Native V4 · DAYFLOW 施工设计（2026-11-02）

## 用户意图
- 保留当前**评委看到的 Apple Native V3**，作为以后随时可访问、完整运行的历史版本；复制 V3 产生新的 Native V4 施工原件。
- 新 V4 是唯一继续施工、发布、评委访问的最新版；固定参赛 URL `https://ndshuge.github.io/xiaoya-lifelab/?judge=1` **永远不更换**，根入口改为指向主仓库内部的 V4，保留 `judge=1` 与其它查询参数。
- 首页优先回答「今天有什么日程」「小芽给我什么建议」；真实日程和任务不能混为一谈，未保存的内容不能凭空生成。
- 改善页面阅读次序与动效，尤其手机端；没有授权不得改写档案、上传私人数据。

## 明确边界
- 官方发布源始终为原仓库 `ndshuge/xiaoya-lifelab`。本次独立分支 `feature/xiaoya-native-v4-dayflow-20261102`。
- `little-works/xiaoya-apple/native-v3/` 原目录文件零改动，版本切换菜单增加 V3 的历史链接。
- 全量复制 V3 文件至 `native-v4/`，避免直接覆盖 V3 及其他研发工作树。V4 保留相对 `../core.js`、`../domain.js`、`../assets/` 等依赖。
- V4 保留数据存储键与 API；personal/demo 独立，不进行隐式迁移或清空。旧版和新版本地存储在同一站点路径下，是相同数据命名空间，版本切换前提示导出。
- 不做尚未开发的日记、情绪、跨端同步、AI 自动任务编辑等功能的虚假入口。页面明确区分「本地规则建议」与已验证的真实 AI。
- 真实写入保持人工批准机制，可撤销；任何新 UI 不允许静默改写日程。

## 本次 V4 可检验交付（R1）
1. 版本隔离：原 V3 和 V4 都可直接访问，V3 的 Git 跟踪文件和源码完整性保留；固定 URL 改为 V4、版本中心和浮动切换也更新。
2. 今日页重新排版：首屏突出真实「下一项日程」及「今日安排」，按实际课表/活动的开始时间排列；真实为空时明确显示空状态，允许引导创建；「小芽的建议」紧随日程，用原 `suggestions(d)` 并保留批准与拒绝；任务显示为「待处理事项」而不伪装成已计划时段。
3. 计划导航：手机与桌面四个主要入口 `今天/计划/成长/记录`，另保留「任务箱」可达；计划页保留周日历与 CSV/ICS 以及查看所有任务；不把现有 tasks 子页删除。
4. 成长页优先展示进行中的目标，成长路线生成器移到目标列表后；原 preview/审批/行动统计不丢。
5. 动效：底部导航选中态自然滑移、页面轻过渡与小芽对话展开从触发方向自然进入；尊重 `prefers-reduced-motion`；所有操作可键盘使用且移动端可点击。
6. 质量与发布：Playwright/Edge+WebKit 的 390px 与桌面验证，真实导航、建议审批、存储隔离、旧版访问、无横向溢出/错误；单独分支提交，先 Fetch 合并远端并在主仓库普通非强制推送；公网复核。

## 明确暂缓（R2/R3）
- 日记与心情记录目前仍在独立研发线，下一阶段需先合并审计并做储存隔离及导入导出验证。
- 复杂日程拖放、前后端 Agent 集成、跨设备同步、真实 Safari 真机检测需要独立验收。
- 保留现有视觉语言，不增加自然景观主题、星芒、花形星号或仪表盘型首页。

## 设计理由
- 保留历代版本隔离能让施工可回滚，且避免新功能意外覆盖比赛已评测代码。
- 清晰区分日程（已安排的课程/活动）、任务（待办）和建议（需要审批），避免学生被误导。
- 现有课表/任务/AI 接口有成熟验证，优先重排 UI 而非重写数据层，风险最低。
## R2 · 2026-11-03 · Apple 结构与交互修订
- 主导航已调整为今天 / 事项 / 发展三项。schedule 和 tasks 组成事项内的日程/任务箱；goals 和 review 组成发展内的目标/复盘。小芽头像独立唤出助手。
- 截止时间可选；无 DDL 任务进入待办池；有 DDL 的任务显示近期截止，不会自动占据课程时间轴；共享 core.js 原本已支持无日期任务，不改 V3。
- 点击当前主导航不重建内容；非路由数据更新不播放整页入场动画；dock 选中胶囊自然滑动，按钮轻按，渐变模糊不拦截触控，支持降低透明度和减少动态效果。
- 使用本机 Apple Design SKILL 的动效可打断、低回弹、空间连续原则，并保持真实数据与 AI 授权边界。
- 独立心情日记数据模型与多设备同步仍是后续阶段；不能伪装已实现，需单独做数据备份与兼容设计。

## 页面设计决策

| 发现的问题 | 具体修复 |
| --- | --- |
| 全局加号、页面标题加号、分组内新增重复 | 删除顶部全局和页标题新增；只在目标内容分组保留语义明确的「添加待办 / 添加截止 / 添加课程 / 添加活动 / 新建目标」。 |
| 新增普通待办就要选择 6 个字段 | 「要做什么」和「截止日期（可选）」直接显示；类别、关联课程、预计分钟、网页提醒收入「更多选项」；编辑时展开详细属性。 |
| 日期视图和独立待办入口混淆 | 从某天的截止提醒创建自动预填当日 23:59；独立待办不预填 DDL；提醒从来不会伪装成课程时间块。 |
| 没有 DDL 仍显示巨大空白卡片 | 去掉空的 DDL 列表卡片，保留添加入口，真实课程提前进入屏幕。 |
| 首页当天课程全部结束还显示第二份时间线 | 今日完成状态变成紧凑单行，提供“下一项安排”和“日程”入口；未结束的课程时间线仍完整展示。 |
| 发展页日记、心情、目标、路线连续堆叠 | 分成「记录／目标」两个局部视图；切换不重建日记编辑器，历史目标、成长规划仍可访问。 |
| 未保存日记切主页面后丢失 | 当前浏览器会话中的草稿以“模式＋日期”为键内存暂存；主动保存才写本地数据，导入和清空会清除旧草稿。 |
| 仅做按钮 44px 检查仍欠缺真实交互 | 对快捷创建、空态、关联日期、草稿、切换、重复点击增加真实浏览器行为测试。 |

## 设计哲学与 Apple 边界

**今天：** 下一步安排与可批准的建议、待办，不要重复时间线。**事项：** 日期、DDL、实际课程、独立待办，输入动作就近。**发展：** 当前情绪／记录与长期目标明确分层。保留小芽头像作为唯一 AI 对话入口。

保持原角色与 Apple-inspired 排版，控制玻璃材质在 Dock 等浮动层；当前为浏览器 L1 渐变模糊，不宣称 iOS 原生 L2 光学折射。保留减少动效、减少透明度和 >=44px 命中区域。演示数据和私人数据隔离；不自动上传日记、未授权不请求模型。

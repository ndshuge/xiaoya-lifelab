# 小芽 Pro · DAYLINE｜时光流域
独立于原版、Apple 版与评委入口的 **Pro 预览版**。以时间为主界面；课程和活动以真实起止时段显示，任务截止时间不会被伪装成学习安排。
- 入口：`/xiaoya-lifelab/pro/`。
- 私人记录只保存在用户自己的浏览器中；不会自动云同步。
- 点击“载入合成演示”查看隔离示例，不会把演示写入私人档案。
- 学期、精细导入等完整管理仍可通过“打开原版完整管理”进入。
- 所有新 Pro 文件位于 `pro/`，包括冻结的 `core.js/domain.js`；不会覆盖既有根目录模块。
- 静态浏览器版本不提供本地 Node 私有服务的模型调用能力。
- 版权：小芽角色复用本项目已有原创资源；成长庭院 SVG 为项目内新增原创矢量景观。
- 仍待设备实测：iPhone Safari 的触摸、输入缩放与持续 60fps；不作虚假承诺。

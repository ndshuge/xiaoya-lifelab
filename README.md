# 小芽 LifeLab · GitHub Pages 公开规则演示

大学生生活管理与成长规划工具的**静态规则演示版**。

- 支持：课表、任务、DDL、规则建议、成长路线、模拟档案与本地复盘。
- 本次新增：可点击 AI 配置入口、每次打开的接入选择、小芽聊天框；未接入时为本机导航。公开版的小芽聊天、三阶段 AI 成长规划和已有规则建议的 AI 排序解释共用一次通过真实模型响应验证的临时 BYOK 连接。规划需逐次授权，并在预览、修改与人工批准后才写入任务；规则建议的 AI 解释需要另行确认。浏览器直连依然可能被 CORS 阻止，服务器同步和后台通知未实现。
- 不含：密钥、私人学籍/课表、评委完整软件包、开发日志。
- 本站数据保存在当前访问浏览器，浏览器清理站点数据后可能丢失。

完整服务端 BYOK 版本仍在独立本地运行包中。公开网页没有自己的 API 代理，也没有预置密钥；用户可在受信任的设备上临时输入自有 Key，直接请求选定服务商；密钥不持久化，刷新即清空。浏览器扩展有潜在风险，避免在公共设备操作。成功请求前始终标识“AI 未接入”。\n\n设计与验收详见 [DESIGN.md](./DESIGN.md)，390px 手机版和 1440px 桌面版的首次弹窗、规则对话和连接入口均通过无密钥 Edge 本地回归，未验证付费模型调用。

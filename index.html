基础课表、任务、桌宠提醒与规则建议不需要 API；“使用我的 API 智能规划”必须配置 Key 并授权。只有通过真实模型响应验证后，才标识 AI 已接入。

GitHub Pages 默认将 Key 保存在本次标签页内存；个人设备可主动勾选“记住此浏览器”，把 Key 存入当前网站的浏览器本地存储（未额外加密，可随时清除）。不会上传到 GitHub 或参赛包。公开网站由浏览器直连模型，可能受提供商 CORS 限制；不要在公共电脑使用自己的付费 Key。

建议先配置，成功后再选择是否测试；连接本身不发起模型请求。

安全限制：仅支持列表中的可信公开 HTTPS API 域名，不允许 localhost、内网地址或任意未审核的代理；每会话每小时最多8次 AI 请求。
